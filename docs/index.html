photo_ops
Python API Reference

High-performance image processing built on a pure-Rust core (PyO3 + Rayon). Signature intelligence, passport cropping, batch processing, cloud I/O — all in one pip install.

⚡ Quick Start 📦 PyPI ⭐ GitHub 💬 Feedback
pip install photo_ops
Windows x64 / x86 Linux x64 / aarch64 / armv7 macOS Intel + Apple Silicon Python 3.8 – 3.13

⚡ Quick Start

Install, import, and process your first image in under 30 seconds.

Install
pip install photo_ops

# Verify Rust core is loaded
python -c "import photo_ops as ip; print(ip.works())"
Single file
import photo_ops as ip

# Convert to grayscale
ip.gray("photo.jpg", "gray.jpg")

# Resize
ip.resize("photo.jpg", "small.jpg", 300, 300)

# Passport crop from portrait
ip.sub_fix("portrait.jpg", "passport.jpg",
           width=400, height=500)
Bytes I/O (no file on disk)
import photo_ops as ip

# Pass a file → get bytes back (output_path=None)
data = ip.gray("photo.jpg", None)

# Pass raw bytes → get bytes back
with open("photo.jpg", "rb") as f:
    raw = f.read()
gray_bytes = ip.gray(raw, None)
Folder / batch (parallel)
import photo_ops as ip

# Process entire folder, 4 workers, audit log
ip.gray("photos/", "gray_out/",
        workers=4,
        log_file="audit.xlsx")

# Adaptive threading (auto-scales)
ip.sub_fix("portraits/", "passports/",
           width=400, height=500,
           workers="auto", stats=True)
Cloud bucket (gs:// / s3:// / az://)
import photo_ops as ip

# Check auth status (see Cloud section)
ip.auth_status()

# Process GCS bucket folder
ip.gray("gs://my-bucket/photos/", "out/",
        workers="auto", log_file="audit.xlsx")

ip.sub_fix("gs://bucket/portraits/", "out/",
           width=400, height=500, workers=4)
Pipeline engine (chain ops)
import photo_ops as ip

ip.process({
    "input":    "scans/",
    "output":   "clean/",
    "ops":      ["fix_turn", "sign_fix", "gray"],
    "workers":  "auto",
    "width":    500,
    "height":   200,
    "stats":    True,
    "log_file": "audit.xlsx",
})

📖 Keywords & Concepts

Core vocabulary used throughout every function signature and docstring.

input_path
Accepts a str file path, a pathlib.Path, a bytes object (raw image data), a local folder, or a cloud URL (gs://, s3://, az://). The library auto-detects which one it is.
output_path
Destination file or folder. Pass None to skip writing to disk and receive the processed image as bytes instead — useful for serving images via a web API.
WorkerSpec
Controls parallelism for folder input. Only effective when processing a folder or list. See the full Workers table below for all accepted values.
BulkResult
A dict[str, str] returned for folder input, mapping each filename to a status string: "success", "not_processed", or "failed: <error>".
log_file
Optional path to an .xlsx or .csv audit log. Auto-created if it doesn't exist. Each row contains filename, status, timestamp, size, and error detail.
stats
If True, prints a summary table after bulk processing — total, success, not_processed, failed, and elapsed time.
skip_if_exists
If True (default), skip re-processing if the output file already exists. Set to False to always re-process.
force
In sign_fix and sub_fix, setting force=True bypasses the quality/confidence classifier and processes every image, even ones that would normally go to not_processed/.
not_processed/
A sub-folder inside the output directory. Images placed here failed quality checks (e.g. no face found, too small) but did NOT crash — they can be re-processed or manually reviewed.
Rayon / GIL
photo_ops releases Python's GIL while inside Rust, letting Rayon threads use all CPU cores simultaneously. Use batch_process() or process() — not a Python for-loop — to get full multi-core benefit.
SeetaFace
The embedded Rust face detector. No external model file needed. Used by has_faces(), sub_fix(), sub_check(), and portrait().
heuristic engine
The signature detection in sign_fix / sign_check uses heuristic scoring — NOT a neural network. This is intentional: COCO-trained models have no "signature" class. The heuristic pipeline is production-grade.

🔧 Workers Spec — All Forms

The workers= parameter accepts many forms. Only applies to folder / list input — ignored for single files.

import photo_ops as ip

ip.gray("photos/", "out/", workers=False)    # serial (1 thread, default)
ip.gray("photos/", "out/", workers=None)     # serial
ip.gray("photos/", "out/", workers=0)        # serial
ip.gray("photos/", "out/", workers=True)     # 10 threads
ip.gray("photos/", "out/", workers=4)        # exactly 4 threads
ip.gray("photos/", "out/", workers=-1)       # cpu_count - 1 threads
ip.gray("photos/", "out/", workers=0.5)      # 50% of logical CPUs (float)
ip.gray("photos/", "out/", workers="4w")     # 4 threads (string shorthand)
ip.gray("photos/", "out/", workers="4t")     # 4 threads (string shorthand)
ip.gray("photos/", "out/", workers="50%")    # 50% of CPUs (string)
ip.gray("photos/", "out/", workers="max")    # all logical CPUs
ip.gray("photos/", "out/", workers="all")    # all logical CPUs (alias)
ip.gray("photos/", "out/", workers="auto")   # adaptive controller (ramps
                                              # up/down with CPU & RAM load)
ValueThreadsNotes
False / None / 01 (serial)Default. Safe, predictable, lowest memory.
True10Quick parallel shortcut.
int ≥ 1exact counte.g. workers=4 → 4 threads.
int < 0cpu − N-1 = cpu_count−1, -2 = cpu_count−2.
float 0.0–1.0N% of CPUs0.5 = 50% of logical CPU count.
"Nw" / "Nt"N threads"4w", "8t" — N workers by string.
"N%"N% of CPUs"50%" = 50% of logical CPUs.
"max" / "all"cpu_countAll logical CPUs. May cause thermal throttling on laptops.
"auto"adaptiveStarts low, ramps up or down based on live CPU temp & RAM. Best for long-running jobs.

💾 Bytes I/O

Every image operation supports in-memory bytes — no temp files on disk.

import photo_ops as ip

# ── File → Bytes (no output file written) ──────────────────────────
gray_bytes = ip.gray("photo.jpg", None)
print(type(gray_bytes), len(gray_bytes))   #  123456

# ── Bytes → Bytes (fully in-memory pipeline) ───────────────────────
with open("photo.jpg", "rb") as f:
    raw = f.read()

gray_bytes   = ip.gray(raw, None)
resize_bytes = ip.resize(raw, None, 300, 300)
blur_bytes   = ip.blur(raw, None, 7)
sign_bytes   = ip.sign_fix(raw, None, width=500, height=200, force=True)
passport     = ip.sub_fix(raw, None, width=400, height=500)

# ── Serve via Flask/FastAPI ─────────────────────────────────────────
# from flask import Flask, send_file
# import io
# app = Flask(__name__)
# @app.route("/gray")
# def gray():
#     data = ip.gray("photo.jpg", None)
#     return send_file(io.BytesIO(data), mimetype="image/jpeg")

# ── Works for ALL functions that have an output_path parameter ─────
for fn_name in ["gray", "resize", "blur", "sharpen", "edges",
                "brightness", "saturation", "tint", "compress",
                "sign_fix", "sub_fix", "enhance_signature",
                "rotate", "flip", "scale", "crop", "crop_center"]:
    fn = getattr(ip, fn_name)
    # fn("photo.jpg", None, ...args...)  →  bytes

☁️ Cloud & Auth

photo_ops supports Google Cloud Storage, Amazon S3, and Azure Blob Storage as drop-in replacements for local paths.

import photo_ops as ip

# ── Check which cloud auth methods are active ──────────────────────
ip.auth_status()
# Prints a table:
# ┌──────────────────────────────┬────────────────┐
# │ Method                       │ Status         │
# ├──────────────────────────────┼────────────────┤
# │ GCP Application Default      │ ✅ Active       │
# │ GCP Service Account          │ ❌ Not set      │
# │ AWS_ACCESS_KEY_ID            │ ❌ Not set      │
# │ AZURE_STORAGE_ACCOUNT        │ ❌ Not set      │
# └──────────────────────────────┴────────────────┘

# ── Set up GCP from terminal ────────────────────────────────────────
# gcloud auth application-default login
# OR set env var:
# export GOOGLE_APPLICATION_CREDENTIALS=/path/to/service-account.json

# ── Set up AWS from terminal ────────────────────────────────────────
# aws configure
# OR:
# export AWS_ACCESS_KEY_ID=...
# export AWS_SECRET_ACCESS_KEY=...

# ── Set up Azure from terminal ──────────────────────────────────────
# az login
# OR:
# export AZURE_STORAGE_ACCOUNT=...
# export AZURE_STORAGE_KEY=...

# ── Use cloud path anywhere a local path is accepted ───────────────
ip.gray("gs://my-bucket/photos/", "out/", workers=4)
ip.sub_fix("s3://my-bucket/portraits/", "out/", width=400, height=500)
ip.sign_fix("az://my-container/sigs/", "out/", force=True)

# ── Download files from cloud ──────────────────────────────────────
ip.download("gs://bucket/photo.jpg", "local.jpg")
ip.download("https://example.com/photo.jpg", "local.jpg")

# ── List cloud folder and get local cached paths ───────────────────
local_paths = ip.resolve_folder("gs://bucket/photos/")
for path in local_paths:
    ip.gray(path, path.replace("/cache/", "/output/"))

# ── Force refresh GCP token ────────────────────────────────────────
ip.refresh_gcp_token()   # call if you see 401 Unauthorized errors

🖼️ Core Functions

ip.gray()
gray(input_path, output_path, skip_if_exists=True, log_file=None, workers=False)
Convert an image or folder of images to grayscale.
bytes I/O cloud workers
▼ 
import photo_ops as ip

# ── Single file ────────────────────────────────────────────────────
ip.gray("photo.jpg", "gray.jpg")

# ── Skip if output exists (default True) ──────────────────────────
ip.gray("photo.jpg", "gray.jpg", skip_if_exists=True)

# ── Result as bytes (output_path=None) ────────────────────────────
data = ip.gray("photo.jpg", None)           # returns bytes

# ── Raw bytes input + bytes output ────────────────────────────────
with open("photo.jpg", "rb") as f: raw = f.read()
gray_bytes = ip.gray(raw, None)

# ── Folder — serial (default) ─────────────────────────────────────
ip.gray("photos/", "gray_out/")

# ── Folder — 4 parallel workers ───────────────────────────────────
ip.gray("photos/", "gray_out/", workers=4)

# ── Folder — adaptive workers + audit log ─────────────────────────
ip.gray("photos/", "gray_out/", workers="auto", log_file="audit.xlsx")

# ── Folder — all CPU cores ────────────────────────────────────────
ip.gray("photos/", "gray_out/", workers="max")

# ── Cloud bucket (GCS) ────────────────────────────────────────────
ip.gray("gs://my-bucket/photos/", "gray_out/", workers=4)
ParameterTypeDescription
input_pathstr | bytes | PathFile path, folder, cloud URL (gs://, s3://, az://), or raw image bytes.
output_pathstr | Path | NoneDestination file or folder. Pass None to receive bytes.
skip_if_existsbool = TrueSkip re-processing if the output file already exists.
log_filestr | NonePath to .xlsx or .csv audit log. Auto-created if not found.
workersWorkerSpec = FalseParallelism for folder input. See Workers Spec section.
Returns: None (file written) | bytes (output_path=None) | dict[str,str] (folder)

import photo_ops as ip

meta = ip.info("photo.jpg")

1
Coarse orientation fix — EXIF metadata + SeetaFace LGC detector → rotates to upright (90° steps).
2
Fine tilt correction — py_detect_tilt_angle sweeps ±15° to find the head-upright angle. Counter-rotates by the detected offset.
3
Face-aware passport crop — ICAO-style framing: crown 15%, chin 78%, side margins 15%. Uses py_smart_crop_v2.
3b
Large-background retry — If no face found on the full image, pre-crops to the inner 60% (strips the large plain border), re-runs tilt detection, then retries face-aware crop. This is what fixes the "passport-with-white-bg" case.
4
Fallback — No face found + force=False → not_processed/. No face found + force=True → centre crop with fixed dimensions.
